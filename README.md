#  Django REST API (Books & Categories)

Учебный проект на Django REST Framework.

##  Функционал

- CRUD для книг 
- CRUD для категорий 
- Swagger документация
- Админка Django

##  Технологии

- Python
- Django
- Django REST Framework
- drf-spectacular

##  Эндпоинты

### Books
- GET /api/books/
- POST /api/books/
- GET /api/books/{id}/
- PUT /api/books/{id}/
- DELETE /api/books/{id}/

### Categories
- GET /api/categories/
- POST /api/categories/
- GET /api/categories/{id}/
- PUT /api/categories/{id}/
- DELETE /api/categories/{id}/

##  Пример категорий

- Фантастика
- Детектив
- Роман
